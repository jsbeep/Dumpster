## 이 컬렉션이 그려져야 하는 모양

```
● OT.홈서버 구축기
● 라즈베리파이 고르기
● OS 설치
● 고정 IP 설정
● 도커 설치                      ⑂① 3갈래 · order 없음 → createdAt 순
├─● 포트포워딩 삽질              11-05
│ ● DDNS 붙이기                  ← 자식 1개면 같은 깊이로 직진
│ ● HTTPS 인증서
├─● 컨테이너 뭐 올리지           11-06 · ⑂② order 순 (a → am → b)
│ ├─● Nextcloud 올리기           a
│ │ ● 용량 부족 사태
│ │ ● 외장 SSD 달기
│ ├─● 모니터링 붙이기            am ← 제일 늦게 썼지만 order로 끼워넣음
│ └─● Jellyfin 올리기            b  · ⑂③
│   ├─● 자막 깨짐                ← createdAt 같음 → 이름순
│   └─● 하드웨어 트랜스코딩
└─● 회고 - 도커 쓸만한가         11-12
── 연결 안 됨 ──
● 공유기 비번 찾기     ⚠ prev 대상 없음 ([[공유기 설정]])
● 닭과 달걀 A          ⚠ prev 순환
● 닭과 달걀 B          ⚠ prev 순환
● 전원 어댑터 메모     ⚠ prev 없음 (속성 자체가 없음)
```

`몰래 쓰는 중`도 prev가 `도커 설치`라 원래는 ⑂①의 네 번째 갈래지만, 태그 `_draft`라서 **아예 안 보인다** (비공개와 똑같이).

하위 폴더 `시즌2`는 **따로 공개 목록에 올려야** 별도 컬렉션이 됨

```
● OT.홈서버 시즌2
● k3s 도전기         ↰ 회고 - 도커 쓸만한가 (다른 컬렉션)에서 이어짐
├─● 노드 하나 더
└─● 노드 하나 더 1     ← 옵시디언 "사본 만들기"로 생긴 글 (속성까지 똑같음)
```

규칙
1. 자식이 1개 → 같은 깊이로 이어 그림
2. 자식이 2개 이상 → **갈래 전부** 한 칸 들여쓰기 (본류 없음)
3. 형제 정렬: `order` → `createdAt` → 이름
4. 루트는 매니페스트(`type: manifest`). prev 없는 일반 글은 연결 안 됨으로
5. prev가 다른 컬렉션이면 그 컬렉션 안에선 루트로 (↰ 이어짐 표시)

## 노드 ID

- 기본은 속성 `oid` — ObjectId(24자리 hex = 앞 8자리 생성 시각 + 랜덤 16자리). Templater가 글 만들 때 넣는다
- 이름을 바꾸거나 createdAt을 고쳐도 ID는 그대로 → 탐색기 URL이 안 깨짐
- oid가 없거나 이상하면 예전 방식 임시 ID: `slug(이름)-yyMMddHHmm`
  - `공유기-비번-찾기-2611040900`
  - `전원-어댑터-메모-{git 첫 커밋 시각}` ← createdAt도 없으면 git
- 겹치면 먼저 생긴 글이 가진다: createdAt → git 첫 커밋 → 경로가 짧은 쪽(사본은 ` 1`이 붙어 길다)

## 탐색 시나리오 (칸이 어떻게 움직이나)

칸 = 흐름 칸 │ 연관 칸(탭). `[ ]` = 띠로 접힌 탭, `*` = 펼친 탭.

| 하는 것 | 칸 | 방식 |
|---|---|---|
| 트리에서 `용량 부족 사태` 클릭 | 용량 부족 사태 | 흐름 교체 |
| 문서 하단 `다음 → 외장 SSD 달기` | 외장 SSD 달기 | 흐름 교체 (트리 선택도 따라감) |
| `도커 설치` 하단 다음 글 | 포트포워딩 / 컨테이너 / 회고 3개 다 나열 (draft는 안 보임) | — |
| `회고` 하단 다음 글 `k3s 도전기` | k3s 도전기 (사이드바가 시즌2로) | 흐름 교체, 컬렉션 넘어감 |
| `용량 부족 사태` 본문 `처음에 깐 OS` 링크 | 용량 부족 사태 │ *OS 설치 | **새 탭** |
| 거기서 바로가기 | OS 설치 (트리에서 선택) | 흐름 칸으로 옮김, 탭에서 빠짐 |
| `HTTPS 인증서` 본문 `Nextcloud 올리기` 링크 | HTTPS 인증서 │ *Nextcloud 올리기 | 새 탭 (다른 갈래로) |
| `회고` see_also `모니터링 붙이기` | 회고 │ *모니터링 붙이기 | 새 탭 |
| 연관 칸이 `[A] *B [C]`일 때 링크 `D` | `[A] [B] *D [C]` | 펼친 탭 바로 뒤에 끼움 |
| 왼쪽 띠 `A` 누르기 | `*A [B] [D] [C]` | 그 탭 펼침, 닫히는 탭 없음 |
| 펼친 탭 × | 오른쪽 탭 펼침, 없으면 왼쪽 | 그 탭만 닫음 |
| 연관 칸에서 이전/다음 | 펼친 탭만 바뀜 (흐름 칸 그대로) | 지금 칸 안에서 |
| `회고` 본문 `공유기 설정` | 클릭 안 됨 (회색 글자) | 없는 문서 |
| `고정 IP 설정` 본문 `통장 비번` | 클릭 안 됨 (회색 글자) | 비공개 = 없는 문서와 구분 안 됨 |
| `회고` see_also `몰래 쓰는 중` | 클릭 안 됨 (회색 글자) | draft = 비공개 |
| 이미 열린 문서로 가는 링크 | 탭에 있으면 그 탭 펼침 / 흐름 칸 글이면 반짝만 | 순환 처리 |
| 뒤로가기 · 앞으로가기 | 직전 칸·탭·스크롤 그대로 | 기록 |
| 주소 복사해 새 탭 | 흐름 글 + 펼친 탭만 (나머지 탭은 안 따라옴) | 공유 링크 |
