## 이 컬렉션이 그려져야 하는 모양

```
● OT.홈서버 구축기
● 라즈베리파이 고르기
● OS 설치
● 고정 IP 설정
● 도커 설치                      ⑂① 3갈래 · order 없음 → createdAt 순
├─● 포트포워딩 삽질              11-05
│ ● DDNS 붙이기                  ← 자식 1개면 같은 깊이로 직진
│ ● HTTPS 인증서
├─● 컨테이너 뭐 올리지           11-06 · ⑂② order 순 (a → am → b)
│ ├─● Nextcloud 올리기           a
│ │ ● 용량 부족 사태
│ │ ● 외장 SSD 달기
│ ├─● 모니터링 붙이기            am ← 제일 늦게 썼지만 order로 끼워넣음
│ └─● Jellyfin 올리기            b  · ⑂③
│   ├─● 자막 깨짐                ← createdAt 같음 → 이름순
│   └─● 하드웨어 트랜스코딩
└─● 회고 - 도커 쓸만한가         11-12
── 연결 안 됨 ──
● 공유기 비번 찾기     ⚠ prev 대상 없음 ([[공유기 설정]])
● 닭과 달걀 A          ⚠ prev 순환
● 닭과 달걀 B          ⚠ prev 순환
● 전원 어댑터 메모     ⚠ prev 없음 (속성 자체가 없음)
```

하위 폴더 `시즌2`는 **따로 공개 목록에 올려야** 별도 컬렉션이 됨

```
● OT.홈서버 시즌2
● k3s 도전기         ↰ 회고 - 도커 쓸만한가 (다른 컬렉션)에서 이어짐
● 노드 하나 더
```

규칙
1. 자식이 1개 → 같은 깊이로 이어 그림
2. 자식이 2개 이상 → **갈래 전부** 한 칸 들여쓰기 (본류 없음)
3. 형제 정렬: `order` → `createdAt` → 이름
4. 루트는 매니페스트. prev 없는 일반 글은 연결 안 됨으로
5. prev가 다른 컬렉션이면 그 컬렉션 안에선 루트로 (↰ 이어짐 표시)

## 노드 ID 예시 (이름 + createdAt)

- `도커-설치-2611041940`
- `자막-깨짐-2611102130` / `하드웨어-트랜스코딩-2611102130` ← 같은 분이어도 안 겹침
- `라즈베리파이-고르기-2611020000` ← 날짜만 있으면 00:00
- `전원-어댑터-메모-{git 첫 커밋 시각}` ← createdAt 없으면 git
