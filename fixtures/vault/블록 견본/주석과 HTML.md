## 주석 (`%%`)
주석은 편집 화면에서만 보인다 %%주석-카나리아-인라인%% 이 문장은 이어져야 함
%%주석-카나리아-한줄%%
윗줄이 주석만 있던 줄이라 이 줄은 같은 문단으로 붙는다

%%
주석-카나리아-여러줄
- 주석 안 리스트도
```
주석 안 코드도
```
%%

> 인용 안 주석 %%주석-카나리아-인용%%도 사라짐

인라인 코드 안은 글자 `100%%` 그대로

## HTML 주석
<!-- html-주석-카나리아 -->

문장 안 <!-- html-주석-카나리아-인라인 --> 주석도 사라짐

## 생 HTML
문장 안 <span style="color:red">빨간 글씨</span> 태그는 글자 그대로, <br>은 줄바꿈

<br>

## 닫히지 않은 주석
여기까지 보이고
%% 주석-카나리아-끝까지
이 줄부터 문서 끝까지 전부 주석
